== Files Changed (iteration 2 — review finding fixes) ==

Review findings from .agents/tasks/mobile-scale-review.json:

Finding 1: `saveRemoteMobileUiScale` throws when profile row is absent.
  Fix: Removed `throw new Error('Profile tidak ditemukan...')`. Now returns `undefined` (no row
       found → silent no-op, consistent with no-session path). Located in mobileUiScale.ts.

Finding 2: Silent sync-up failure on first device swallows errors with no log.
  Fix: Changed `catch {}` to `catch (err) { console.warn('[MobileUiScale] Failed to push local
       scale to remote:', err); }` in `syncRemoteMobileUiScale`. Located in mobileUiScale.ts.

Finding 3: `Profile.mobileUiScale` type omits `null`.
  Fix: Changed `mobileUiScale?: number` to `mobileUiScale?: number | null` in `Profile` interface
       (src/types/index.ts) to align with DB NUMERIC nullable semantics.

Additional: Added 2 new tests to mobileUiScale.test.ts covering the fixed behaviours:
  - `saveRemoteMobileUiScale` returns undefined (not throws) when profile row missing.
  - `syncRemoteMobileUiScale` logs a console.warn on sync-up network error.
